# Задание 7. Динамическое связывание

В примере родительский класс `Transformer` задаёт общую операцию проверки
перегрузки. Конкретные классы трансформаторов переопределяют эту операцию
в соответствии со своим назначением.

```python
# Родительский класс задаёт общий контракт для всех трансформаторов.
# Клиентскому коду достаточно знать, что любой трансформатор
# умеет проверять перегрузку.
class Transformer:

    def check_overload(self) -> None:
        raise NotImplementedError(
            "Класс-наследник должен реализовать проверку перегрузки"
        )


# Специализация родительского класса для трансформатора тока.
# Метод с тем же именем переопределён под проверку тока.
class CurrentTransformer(Transformer):

    def check_overload(self) -> None:
        print("Проверяем перегрузку по величине тока")


# Специализация родительского класса для трансформатора напряжения.
# Здесь тот же метод уже содержит другую реализацию.
class VoltageTransformer(Transformer):

    def check_overload(self) -> None:
        print("Проверяем перегрузку по величине напряжения")


# Клиентский код работает с общим типом Transformer.
# Внутри функции мы не выясняем вручную, какой именно класс нам передали.
def inspect_transformer(transformer: Transformer) -> None:
    transformer.check_overload()


current_transformer = CurrentTransformer()
voltage_transformer = VoltageTransformer()

# Строка вызова в обоих случаях одна и та же.
# Однако Python во время выполнения смотрит на фактический класс объекта
# и сам выбирает нужную реализацию метода check_overload().
inspect_transformer(current_transformer)
inspect_transformer(voltage_transformer)
```

Результат выполнения:

```text
Проверяем перегрузку по величине тока
Проверяем перегрузку по величине напряжения
```

В данном примере динамическое связывание применяется в функции
`inspect_transformer()`. Клиентский код вызывает один общий метод
`check_overload()`, не указывая конкретную реализацию. Нужный метод выбирается
автоматически во время выполнения программы в зависимости от фактического
класса переданного объекта.

За счёт этого при добавлении нового вида трансформатора функцию
`inspect_transformer()` изменять не потребуется. Достаточно создать нового
наследника `Transformer` и реализовать в нём метод `check_overload()`.
