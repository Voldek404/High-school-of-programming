В Python класс можно рассматривать как модуль: внутри него объединяется законченный набор связанных операций, предназначенных для выполнения определённой задачи.
 Класс предоставляет другим частям программы определённые службы через публичные методы и скрывает детали их реализации. 
Такой класс можно импортировать и целиком использовать в другом коде.
Наследование при этом служит механизмом повторного использования кода: новый класс-модуль получает операции родительского класса-модуля и дополняет их новыми операциями.
 Таким образом, наследник расширяет набор служб родителя, не дублируя уже существующую реализацию.
